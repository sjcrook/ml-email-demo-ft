# ml-email-demo-ft
MarkLogic Email Demo for APG build using MarkLogic Fasttrack

## What It Does

The demo loads email, transcript, and trade records into MarkLogic and exposes
them through a React search application. Analysts can search by collection,
filter with facets, inspect source documents, review transcript relationship
graphs, and open alerts generated from trade-related activity.

The runtime consists of:

- `datahub/`: MarkLogic Data Hub configuration, search options, transforms, and data loading.
- `proxy/`: Express proxy that handles browser requests and MarkLogic Digest authentication.
- `ui/`: Vite, React, TypeScript, KendoReact, and `ml-fasttrack` application.
- `data/`: line-delimited source records for emails, transcripts, and trades.

## Data Model

| Document type | Collection | URI pattern | Notable fields |
| --- | --- | --- | --- |
| Email | `/type/emails` | `/emails/{id}.json` | sender, recipients, date |
| Transcript | `/type/transcripts` | generated by the transcript transform | speakers and call date |
| Trade | `/type/trades` | `/trades/{TradeID}.json` | `Broker`, `Security`, `TradeDate`, `TradeDateTime` |
| Alert | `alerts` | generated by the alert flow | `URI`, `referringDocs`, `triggerWords` |

The `Broker` facet is backed by a string path-range index on `/trade/Broker` and
the `Broker` search constraint in `datahub/src/main/ml-modules/options/all.xml`.

## Ports

- MarkLogic container ports: `7997-8004` and `8006-8020` are published by Docker.
- Proxy: `8091` in `proxy/.env_SAMPLE`.
- Proxy target: `8011` by default in `proxy/.env_SAMPLE`; set this to the deployed MarkLogic application-server port.
- UI: Vite chooses and prints the development port, commonly `5173` or `5174`.

## Setup Instructions

### Start container environment

```
docker compose up -d
```

\# Wait 30s then...

### Bootstrap MarkLogic

```
cd datahub
./gradlew mlDeploy -i
```

### Load data into MarkLogic

\# See docker-compose.yml for MarkLogic admin credentials (I'm using 8011 for the port)  
```
./load_data.sh <ml_admin_usn> <ml_admin_pwd> <port>
```

\# IN ANOTHER COMMANDLINE WINDOW...

### Start the proxy

```
cd proxy
```  
\# copy .env_SAMPLE to .env and modify if required  
\# open .env and set TARGET_PORT to the application server port of the database  

```
npm install  
node proxy.js
```

\# IN ANOTHER COMMANDLINE WINDOW...

### Start the UI
```
cd ui  
```
\# copy .env_SAMPLE to .env and modify if required  
```
npm install  
npm run dev  
```
\# open a browser on the port given what it says on the screen  
\# go to http://localhost:<port>/signin and sign in as the MarkLogic admin  
\# Visit 2 pages:  
\#    - /app/search  
\#    - /app/alerts

## Verification

After the services are running, sign in at `/signin` and verify:

1. Search results load for each collection menu item.
2. The Broker facet is visible and filters trade results.
3. Trade documents open in the Document tab. Relationship Graph is available for transcript documents only.
4. The bell opens Alerts; expanding an alert subject lists its source trade URI and related document URIs.
